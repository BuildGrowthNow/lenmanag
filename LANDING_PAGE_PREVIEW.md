## Color Scheme

### Primary Colors
- **Background**: Dark gradient (Slate 950 → 900 → 950)
- **Text**: White / Light Slate
- **Accent**: Yellow 500/600 (🟡)
- **Secondary**: Purple touches

### Visual Effects
- Animated floating gradient orbs in background
- Glassmorphic cards (white/5 opacity + blur)
- Yellow glow shadows on CTAs
- Smooth hover animations (scale + shadow)
- Gradient text on headlines

## Animations

### On Page Load
1. Hero text fades in + slides up
2. Badge scales in
3. Stats cards fade in with stagger
4. Background orbs start floating

### On Scroll (as elements enter viewport)
1. Feature cards fade in + slide up
2. Process steps animate in sequence
3. Checklist items appear one by one
4. Pricing cards slide in from sides

### On Hover
- Buttons: Scale 1.05 + increase glow
- Cards: Lift up (translateY -10px)
- Stats: Scale 1.05
- Links: Underline + color shift

### On Click/Tap
- Buttons: Scale 0.95
- Forms: Focus yellow border glow

## Typography

### Headlines
- **Main Hero**: 8xl (96px) - Bold
- **Section Headers**: 5xl (48px) - Bold
- **Card Titles**: 2xl (24px) - Bold

### Body Text
- **Large**: xl (20px) - Regular
- **Medium**: lg (18px) - Regular
- **Small**: sm (14px) - Regular
- **Muted**: slate-400

### CTAs
- **Primary Button**: lg (18px) - Bold
- **Secondary Button**: lg (18px) - Semibold

## Sections Breakdown

### 1. Hero (Above Fold)
- **Purpose**: Grab attention, communicate value
- **Key Message**: "Your Website. In 3 Days."
- **CTA**: Get Started Now (scroll to pricing)
- **Social Proof**: 4 stats boxes

### 2. Features (Why Choose Us)
- **Purpose**: Differentiate from competitors
- **Layout**: 3x2 grid of feature cards
- **Design**: Icon + Title + Description
- **Animation**: Staggered fade-in on scroll

### 3. Process (How It Works)
- **Purpose**: Show simplicity
- **Layout**: 3 steps in a row with connector
- **Design**: Number badge + Title + Description
- **Animation**: Sequential appearance

### 4. Inclusions (What You Get)
- **Purpose**: Show comprehensive value
- **Layout**: 2-column checklist
- **Design**: Checkmark + Feature name
- **Animation**: Items slide in from left

### 5. Pricing & Form (CTA)
- **Purpose**: Convert visitors to customers
- **Layout**: 2-column (pricing left, form right)
- **Design**: Prominent price, clear form fields
- **CTA**: Dual CTAs (pay now + submit form)

### 6. Final CTA (Reinforcement)
- **Purpose**: Catch undecided visitors
- **Layout**: Centered, minimal
- **Design**: Large text + single button
- **Background**: Gradient overlay

### 7. Footer (Trust)
- **Purpose**: Professional closure
- **Layout**: Centered text
- **Design**: Simple copyright + tagline

## Responsive Design

### Desktop (1280px+)
- Multi-column layouts
- Large typography
- Full animations

### Tablet (768px - 1279px)
- 2-column grids become 2-column
- Slightly smaller text
- Same animations

### Mobile (< 768px)
- All grids become single column
- Text size reduced (6xl → 5xl)
- Simplified animations
- Touch-optimized buttons

## Technical Implementation

### Tech Stack
- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS
- **Components**: shadcn/ui
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Payment**: Stripe Payment Links
- **Forms**: React state + API route

### Performance
- Lazy load animations (viewport triggers)
- GPU-accelerated transforms
- Optimized re-renders
- No external scripts except Stripe

### Accessibility
- Semantic HTML
- ARIA labels where needed
- Keyboard navigation
- Focus states
- High contrast ratios
