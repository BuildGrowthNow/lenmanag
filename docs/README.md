# LenQuant Website Fabric

This documentation defines the system for discovering lead websites, extracting public context, generating premium redesigns, and supporting outreach and fulfillment from a single internal operator platform.

The core workflow is:

1. import or create a lead
2. extract public site context
3. generate a premium preview
4. apply operator overrides when needed
5. regenerate safely from the stored spec
6. export or share the result for the next sales step
